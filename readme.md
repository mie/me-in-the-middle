# Me-In-The-Middle

Установка сторонних корневых сертификатов в доверенное хранилище операционной системы - очевидный и огромный риск безопасности. Особенно если это сертификаты Мин.Цифры. Но мы изолируем этот риск в docker-контейнер, через который будем проксировать лишь необходные соединения.

## Описание

Данный проект - всего лишь Dockerfile, используя который можно поднять собственный прокси сервер и посещать выбранные сайты, используя сторонние сертификаты. Образ получается леговесный и почти не требовательный к ресурсам. Рабочий процесс потребляет от 60 до 90 МБ RAM с околонулевой загрузкой CPU.

## Начало работы

### Зависимости

* docker / podman
* Windows / Linux / MacOS

### Инструкция

Все действия необходимо выполнять в командной строке или эмуляторе терминала. В примерах используется docker и docker compose. При использовании podman и podman compose достаточно заменить в командах docker -> podman.

```
$ git clone https://github.com/mie/me-in-the-middle.git
$ cd me-in-the-middle
```

Далее в папку me-in-the-middle необходимо скопировать сторонние файлы сертификатов (*.cer), которые будет использовать прокси. Корневые сертификаты Мин.Цифры - три файла Russian_Trusted_Sub_CA.cer, Russian_Trusted_Sub_CA.cer и Russian_Trusted_Sub_CA_2024.cer. Скачать их нужно с сайта [ГосУслуги](https://www.gosuslugi.ru/landing/crt), взяв ссылки в разделе настройки для Linux. После этого выполяем:

```
$ docker compose up -d
```

Всё, прокси работает. Теперь нужно настроить подключение к ней. Для подключения по HTTPS она генерирует свой собственный сертификат, который мы и импортируем к себе. Он зашифрует соединение между прокси и браузером.

В файловой системе контейнера он расположен в папке /root/.mitmproxy/mitmproxy-ca-cert.pem - нужно скопировать его из контейнера. Если вы используете Docker Desktop для Windows, можно раскрыть контейнер gov-proxy, зайти на вкладку Файлы, найти сертификат и сохранить к себе в основную систему через пункт контекстного меню. А через терминал вот так:

```
$ docker cp gov-proxy:/root/.mitmproxy/mitmproxy-ca-cert.pem ./ca.pem
```

Файл ca.pem - это и есть сертификат нашей прокси. Теперь этот его нужно добавить в браузер. Для этого есть два варианта:

1. Установить его как корневой сертификат операционной системы.

В Linux - это копирование файла в каталог /usr/local/share/ca-certificates/ и выполнение команды `update-ca-certificates`. 

В MacOS - установка в Keychain из контекстного меню файла в Finder.

В Windows - установка в корневые сертфикаты также через контекстное меню файла в Проводнике.

2. Использовать веб-браузер Firefox и установить сертификат только в него

Этот вариант намного удобнее - здесь вы сами выбираете, на какие сайты заходить через прокси, а на какие - напрямую. Помимо этого Firefox более гибок в плане настройки блокировки рекламы, трекеров и прочих вредных сетевых сущностей.

1. Открываем Firefox

2. Через меню приложения переходим в настройки

3. Выбираем раздел Приватность и защита (Privacy and security)

4. Листаем в самый низ страницы настроек, кликаем на кнопку Безопасность соединений и программного обеспечения (Connection and software security)

5. Новую страницу снова прокручиваем в самый низ до карточки Сертификаты (Certificates). Нажимаем на Управление сертификатами (Manage certificates). Переходим на вкладку Центры сертификации.

6. В появившемся окне нажимаем кнопку "Импортировать..." (Import...), выбираем скопированный из контейнера файл `ca.pem`, используем для сетевых подключений

Теперь необходимо настроить Firefox на подключение к нашей прокси для выбранных сайтов. Для этого лучше всего использовать бесплатное расширение [FoxyProxy Standard](https://addons.mozilla.org/ru/firefox/addon/foxyproxy-standard/).

Устанавливаем его в Firefox, затем открываем настройки, переходим на вкладку Прокси, нажимаем Добавить. Указываем любое наименование, выбираем тип HTTP, хост - localhost, порт 8080. Также можно выбрать цвет ярлычка, чтобы выбранный прокси отличался от других визуально. Сохраняем.

Теперь в меню FoxyProxy появился наш прокси, и его можно выбирать либо для текущей вкладки, либо включить и использовать во всех вкладках до отключения.
